# Portfolio Design Studio: Project Rules & Guidelines

> Источник документации: [docs/project_info.md](file:///Users/wiktorbuksza/Dropbox/www.buksha.design/docs/project_info.md)

Данный сайт является портфолио для дизайн-проектов, специализирующегося на motion-дизайне, 3D-визуализации и кинематографической эстетике.

## Основная концепция
- **Стиль**: Минимализм, премиальный вид, акцент на типографике и визуальном контенте.
- **Цель**: Демонстрация кейсов через динамические сетки и видео-превью.

## Технологический стек
- **HTML5**: Семантическая разметка.
- **CSS3**: Vanilla CSS с использованием CSS Grid и Flexbox.
- **Шрифт**: Instrument Sans (подключен через Google Fonts).
- **JavaScript**: Использование Intersection Observer для анимаций появления (Scroll Reveal).

## Структура проекта
- `index.html` — главная страница.
- `style.css` — стили и дизайн-система.
- `main.js` — интерактивность и анимации.
- `Video/` — директория для видео-ассетов.
- `docs/` — документация проекта.

## Важные инструкции
- **Сетки**: Используются комбинированные сетки (2-колонки с большими блоками и 3-колонки с деликатным прокручиванием влево).
- **Медиа**: Проекты могут содержать как изображения, так и видео (`<video autoplay muted loop>`).
- **Шрифты**: Основной шрифт — **Instrument Sans**. Не менять без согласования.

## Дизайн-система: Display Button
`Display Button` — это унифицированный стиль кнопок-категорий (ярлыков) для обозначения разделов сайта (например, `Selected works`, `Services`):
- **Стиль**: Тонкая деликатная рамка (`1px solid`), скругление углов `100px` (форма пилюли), внутренние отступы `0.45rem 1.1rem`.
- **Типографика**: Шрифт `Instrument Sans` (`0.72rem`), полужирный (`font-weight: 600`), полностью в верхнем регистре (`uppercase`), увеличенный межсимвольный интервал (`letter-spacing: 0.08em`).
- **Темы**:
  - *Светлая тема (по умолчанию, например, Selected Works)*: черный фон (`#000000`), черная рамка (`#000000`), белый текст (`#ffffff`). На ховере — инверсия в прозрачный фон, черный текст и черную рамку.
  - *Темная тема (внутри .stats, например, Services)*: белый фон (`#ffffff`), белая рамка (`#ffffff`), черный текст (`#000000`). На ховере — инверсия в прозрачный фон, белый текст и белую рамку.
- **HTML-класс**: `.display-button` (для темного фона на темных секциях `.stats` автоматически переключается, либо можно использовать класс `.display-button--dark`).
